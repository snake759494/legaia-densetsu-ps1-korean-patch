# 번역 작업 지침 (레전드 오브 레가이아 대사)

작업 폴더: `D:\ps1\레전드오브레가이아\work` (모든 명령은 이 폴더에서 실행)

## 입력과 출력
- 입력: `text/ja/bNN.json` — `[{"id", "ja": [줄...], "w": 줄 최대 글자, "tot": 전체 최대 글자}]`
- 출력: `text/ko/bNN.json` — `[{"id": 같은 id, "ko": [줄...]}]` (입력의 모든 id를 빠짐없이, UTF-8 JSON)
- 용어: `text/glossary.md`를 먼저 읽고 반드시 따릅니다.

## 글자 수 제한 (가장 중요)
게임 데이터 크기를 바꿀 수 없어서 원문 바이트 안에 맞춰야 합니다.
- `ko` 줄 수 = `ja` 줄 수 (정확히 같아야 함). 한 덩어리(대사창 한 장)의 줄 나눔은 자유롭게 바꿔도 됩니다(줄 수만 같으면 됨).
- 각 줄 글자 수 ≤ `w`, 모든 줄 글자 수 합 ≤ `tot`.
- 글자 수 세는 법: 한글 1자, 공백 1자, 문장부호 1자, 숫자·영문 1자, `{N}` `{f101}` 같은 토큰은 1자.
- 남는 칸은 빌드할 때 자동으로 공백으로 채웁니다. 짧게 번역해도 됩니다.
- 넘치면 의미를 살리면서 줄이세요(조사 생략, 짧은 동의어, 띄어쓰기 줄이기 등). 대사가 너무 빽빽하면 공백을 줄여도 됩니다.

## 표기
- 사용할 수 있는 문자: 한글 완성형, 숫자, 영문, 공백, 그리고 `, . ! ? ( ) : / % & + - ~ * = < >` 와 `、。…！？「」『』〈〉【】・ー～♂♀★◆Φ`.
- 일본어 가나·한자를 출력에 남기지 마세요(검사기가 잡습니다). 단, `{....}` 토큰 안은 예외.
- `{N}` `{f101}` `{f102}` `{f2xx}` 등 중괄호 토큰은 원문과 같은 개수로 유지합니다.
- `♂`(물음표형)·`♀`(느낌표형)·`★` 등 특수 기호는 원문과 같은 자리(문장 끝)에 둡니다.
- 말하는 사람: `メイ「…` → `메이「…`. 둘째 줄 이후의 앞 공백 들여쓰기(전각 공백 1개)는 원문처럼 유지(공백 1개로 써도 됨).
- 원문에서 단어 사이 전각 공백(`　`)으로 띄운 부분은 한국어 띄어쓰기로 자연스럽게 바꿉니다.
- 내부 디버그용 문구(`フラグ`, `＜…＞`, `＝ＥＸＩＴ＝`, 영문 약어 라벨 등)는 짧게 번역하거나 영문/기호는 그대로 둡니다.

## 문체
- 자연스러운 한국어 게임 대사. 원문 말투(노인, 아이, 공손, 거친 말투)를 살립니다.
- 히라가나만 쓰는 아이/짐승 말투는 쉬운 말로.
- 같은 배치 안에서 같은 문장은 같은 번역으로 통일합니다.
- 절대 외부 번역기/웹 서비스를 쓰지 말고 직접 번역합니다.

# 기타 텍스트(m0~m3: 메뉴·아이템·기술·전투 메시지·미니게임)
- 입력: `text/ja/mN.json` — `[{"id","ja": 문자열("\n"은 줄바꿈),"max": 최대 글자 수,"src": 출처}]`
- 출력: `text/ko/mN.json` — `[{"id","ko": 문자열}]`
- 글자 수(줄바꿈 제외) ≤ `max`. 줄바꿈(`\n`) 개수는 원문과 같게.
- `{f100}` `{f101}` `{f102}` `{f2xx}` 등 토큰과 사용자 정의 문자(~)는 원문과 같은 개수로 유지.
- 아이템·기술 이름은 짧고 명확하게. 영어 외래어 기술명(バーニングアタック 등)은 한국어 음역(버닝 어택). 글자 수가 모자라면 띄어쓰기를 빼거나 줄임.
- 원문이 가운데 정렬용으로 앞에 전각 공백을 둔 경우 비슷하게 공백을 둬도 됩니다.
- 검사: `python tools/chk_misc.py mN` → `오류 0 누락 0`.
