# 기술 설명

## 디스크 구성

| 파일 | 내용 |
| --- | --- |
| `SCPS_100.59` | 실행파일. 전투 훔치기 메시지, 일부 기술 설명, 한자 글꼴 선택 코드 |
| `PROT.DAT` | 거의 모든 게임 데이터(맵 스크립트, 메뉴, 전투, 그림, 음악). 앞쪽 TOC + 파일 1,000여 개 |

`PROT.DAT` 안의 파일은 하위 컨테이너(`[개수][전체 크기][(크기|종류<<24, 오프셋)]*N`)로 되어 있고, 청크마다 LZSS 압축 여부가 다릅니다(`tools/pack.py`, `tools/chunks.py`). LZSS는 Okumura 방식(4,096바이트 링, 시작 위치 0xFEE)입니다(`tools/lzs.py`).

번역을 넣고 다시 압축하면 파일이 원래보다 커질 수 있습니다. 이때는 원래 위치를 최대한 유지하되, 넘치는 파일 뒤의 파일들을 밀어서 배치하고 TOC를 갱신합니다(`tools/protw.py`). 게임은 TOC를 디스크에서 읽으므로 이 방식으로 동작합니다. 디스크에는 바뀐 섹터만 다시 쓰고 Mode2 Form1의 EDC/ECC를 다시 계산합니다(`tools/disc.py`, `tools/cdsec.py`). 결과 BIN은 원본과 크기가 같습니다.

## 문자열

- 텍스트는 2바이트 Shift-JIS입니다. 맵 스크립트의 대사는 `[글자 수][글자...]` 형식의 줄이 이어진 런입니다(`tools/sstr.py`, `tools/extract.py`).
- 토큰: `F1 00` 주인공 이름, `FF xx`·`F7 xx` 제어 코드, `FE 00`·`FE 02` 버튼 아이콘 등. 번역문에는 `{f100}` 같은 형태로 적고 개수를 원문과 같게 유지합니다.
- 메뉴·전투 메시지 등은 여러 형식이 섞여 있습니다.
  - `[개수][문자열][00]`
  - 개수 없이 널로 끝나는 문자열
  - 줄마다 글자 수가 붙은 체인 `[n1]줄1[n2]줄2...[00]`
  - 형식별 추출기: `tools/misc_extract.py`, `tools/misc2_extract.py`, `tools/chain_extract.py`, `tools/nscan.py`, `tools/zscan.py`
- 번역은 원문 자리에 덮어씁니다. 런 안에서 줄 길이는 재배분할 수 있지만, 전체 글자 수는 원문을 넘을 수 없습니다(`tools/chk.py`, `tools/chk_misc.py`).
- 추출기가 놓친 전투·튜토리얼 문자열은 원문 바이트를 찾아 같은 자리에 기록합니다(`tools/rawtxt.py`).
- 전투 기술 이름(파일 865~867)과 적 이름(파일 869)은 LZSS로 압축된 데이터 안에 있습니다. 풀어서 이름만 바꾸고 다시 압축하며, 원래 슬롯(적 데이터는 0x14000바이트) 안에 들어가는지 검사합니다(`tools/arts.py`, `tools/mon.py`).

## 한글 글꼴

게임은 한자를 PROT.DAT 안의 한자 글꼴 TIM에서 꺼내 그립니다.

- **코드 배정**: 번역에 쓰인 한글 1,162자를 SJIS 한자 코드 자리에 배정합니다(`tools/kfont.py`, `text/kmap.json`).
- **글리프**: 배정한 자리의 글리프를 갈무리11 12px로 그려 넣습니다. 원본 픽셀 그대로 넣고 늘이거나 줄이지 않습니다.
- **글꼴 선택 코드**: 실행파일에서 한자 코드일 때 축소 글꼴을 고르는 분기를 바꿔, 항상 전체 글꼴을 쓰게 했습니다.
- 기본 글꼴의 `、` `。`는 한국어 문장에 맞게 쉼표·마침표 모양으로 다시 그렸습니다.

## 그림 글자

TIM 이미지의 4비트 인덱스를 직접 고칩니다. 원래 글자 영역의 배경색을 추정해 지운 뒤 한글을 그리고, 테두리 색을 원본과 맞춥니다(`tools/imgutil.py`).

- 전투 UI(파일 0): 상태 이상·장비 칸 라벨(`tools/gfx.py`)
- 슬롯머신 화면, 「무투회」 타이틀, 상태 이상 아이콘(`tools/imgpatch.py`)
- 스태프롤 26장: 직책·캐릭터 이름·회사 이름만 한글로 바꾸고, 실명은 원문 그대로 둡니다(`tools/staff.py`).

## 검사

- `tools/scanjp.py`: 빌드한 BIN에서 남은 가나, 또는 한글 배정표에 없는 한자를 전수 조사합니다.
- `tools/uncovered.py`: 기타 문자열 추출이 덮지 못한 일본어를 찾습니다.
- 남겨 둔 일본어: 화면에 나오지 않는 스크립트 디버그 라벨, 사운드 테스트 메뉴 일부, 글꼴·이름 입력 원본 표.
